# Legacy Archive

This folder contains material from the previous academicpages/minimal-mistakes based site and local design experiments.

The active public site does not depend on these files. `_legacy/` is excluded in `_config.yml`, so this archive is not published by Jekyll.

## Contents

- `academicpages/` - old layouts, includes, Sass, JS, sample pages, sample images, comments data, and helper tooling.
- `mockups/` - old standalone mockup files.
- `notes/` - older planning notes and fix lists that no longer match the current positioning.

Keep this folder for reference until the current custom template has been live for a while. Delete it later only after confirming nothing useful remains.
